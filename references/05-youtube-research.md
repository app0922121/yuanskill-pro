# 05 · YouTube 调研（L5 视频层，默认必做）

## 依据
- 用户 2026-11-06 要求：任何问题的调研，YouTube 都是默认的一部分。
- 工具实测（2026-11-06，本机 yt-dlp 2026.10.26 + deno 2.9.8）：
  - WebSearch 加 `site:youtube.com` 返回的 7 条结果里，没有一条是 YouTube 链接。WebFetch 读视频页只拿到标题。**两者都不能用来做 YouTube 调研。**
  - `yt-dlp ytsearchN:` 能稳定拿到候选视频；原语言字幕（`*-orig`）和人工字幕能下载；**自动翻译字幕会返回 HTTP 429**。来源是 yt-dlp issue #13831，维护者 2026-01 置顶说明。
  - 测了 3 条中文视频，2 条完全没有字幕。中文题目在 YouTube 上能读到正文的比例偏低，要靠 §5 降级。
- 浏览器打开文稿面板，本次测试没有渲染出来，不能当作稳定的取字幕通路。

## 何时读
阶段 2 填 L5 视频层时读。BASIC 模式同样要做。

---

## §1 取数：一律走脚本

```bash
S=~/.claude/skills/yuanskill-pro/scripts/yt_research.py
python3 $S search "<关键词>" -n 10 --meta 5        # 候选表：播放量/频道/时长/发布日期/播放÷订阅
python3 $S transcript <URL> --out <调研目录>/yt    # 字幕 → 带 [mm:ss] 的纯文本
python3 $S info <URL>                              # 没有字幕时：取简介与章节
```

- 退出码：0 成功；2 没有字幕（转 §5）；3 缺 yt-dlp（先问用户能不能装，不能装就转 §5）；4 调用失败（等一会儿重试一次，仍然失败就在覆盖表填「不可达」）。
- 字幕存到调研目录，不要存进 skill 目录。字幕原文由子代理读，主会话只看提炼结果。

## §2 搜什么

每个题目至少搜 **3 组关键词**，中文、英文都要有。语言按「这个领域最权威的语言」选，参见 01 §4.1：

| 组 | 模板 |
|---|---|
| 做法 | "<任务> tutorial / workflow / how I" ·「<任务> 教程／实操」 |
| 标杆 | "<头部产品名> review / vs / demo" |
| 踩坑 | "<任务> mistakes / doesn't work / lessons" ·「<任务> 踩坑」 |

做技术类题目时，再加一组带当年年份的关键词，用来过滤过时内容。

## §3 挑哪几条看（先列候选，再挑 3–5 条读正文）

按下面的顺序筛，**挑选理由写进覆盖表备注**：

1. **相关**：标题和章节对得上要回答的问题。
2. **频道类型**：官方或产品方 > 一线从业者（展示了自己的真实工作流）> 教程搬运号。
3. **时效**：技术类优先看 12 个月以内的。超过 12 个月的只用来看「做法是怎么演变的」。
4. **吸引力**：播放量 ÷ 订阅数 ≥1，说明内容本身吸引人；比值远小于 1，主要靠频道订阅基数撑着。**这个阈值是经验值，还没在实战中校准。**
5. **排除**：
   - 标题党：标题和字幕前 2 分钟对不上；
   - AI 垃圾频道：TTS 配音、日更好几条、简介里堆外链；
   - 纯搬运或翻译他人视频的。

## §4 读字幕时提炼什么

每条视频只按下表抽取，写进调研文件：

| 主张 | 机制（为什么有效） | 证据（演示/数据，带时间戳） | 适用边界 | 来源 |
|---|---|---|---|---|
| … | … | `[07:32]` 现场演示 … | … | URL&t=452s · 原语言自动字幕 |

- **同一个机制，要有 2 个以上独立频道提到，才算共识**；只有一个频道说的，标「单一来源」。
- 自动字幕里的专有名词和数字，要回到简介或画面核对；核对不了的，标「自动字幕·未核」。
- 和 L1–L4 层的结论冲突时，两边都写出来，不在这里裁决。

## §5 降级顺序（拿不到字幕时）

1. `info`：用简介、章节代替正文。由此写出的结论标「未读正文·据简介/章节」。
2. 找同一作者的博客、推文、GitHub 仓库、演讲稿。
3. 第三方转录站或笔记站的内容，标「二手转录」，可信度降一级。
4. 以上都不行，就只把「标题 + 频道 + 播放量 + 日期」记作线索。**不能根据标题推断视频内容。**
5. 中文题目在 YouTube 上取不到正文时，可以用浏览器只读打开 B 站搜索页，补一轮候选，规则同 §3。

**不可达必须写明**。抓取失败不能悄悄当成「没有相关视频」。

## §6 禁止
- 不用 WebSearch 或 WebFetch 代替 YouTube 搜索或读取。
- 不手动拼字幕接口（timedtext）的 URL，不用切换客户端等方式绕过反爬检测。
- 不请求自动翻译字幕（会触发 429，连累同一 IP 下的后续请求）。
- 对视频只读不写：不点赞、不评论、不订阅。
